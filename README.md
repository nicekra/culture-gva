# culture.gva

Toute la culture du Grand Genève, au même endroit. Version web installable (iPhone : Safari › Partager › Sur l'écran d'accueil).

Données : agenda de la Ville de Genève et agendas des lieux publiés sur OpenAgenda (Licence Ouverte 2.0). Fond de carte : OpenFreeMap / © contributeurs OpenStreetMap.

Ce dépôt ne contient que le site compilé.
